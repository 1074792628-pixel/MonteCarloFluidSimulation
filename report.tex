\begin{abstract}
本实验实现了两种基于 Monte Carlo 的不可压缩流体仿真方法，并进行了系统对比：
2022 年 Rioux-Lavoie et al. 提出的\textbf{涡量法}\cite{rioux2022}（涡量输运 + Biot-Savart 重建速度 + 流函数 WoS 处理边界），
以及 2024 年 Sugimoto et al. 提出的\textbf{速度法}\cite{sugimoto2024}（速度算子分裂 + Walk-on-Boundary 投影维持不可压缩性）。
两种方法的根本区别在于流体状态的表示：涡量法以标量涡量场 $\omega$ 为状态变量，通过 Biot-Savart 积分重建速度，
天然满足 $\nabla\cdot\boldsymbol{u}=0$；速度法直接以速度场 $\boldsymbol{u}$ 为状态，通过投影步骤显式维持不可压缩性。
实验在 Taylor-Green 涡流场上对两种方法进行了对比，考察了动能演化、涡量守恒和计算开销。
结果表明：涡量法计算代价高（每步约为速度法的 18 倍），但物理量（环量、涡量）守恒性更好且不存在压力投影的噪声反馈问题；
速度法计算高效，但依赖投影步骤且数值耗散较大。两种方法各有适用场景，涡量法更适合强调物理守恒的研究性仿真，
速度法更适合追求效率的动画级应用。
\end{abstract}

\section{引言}

传统的计算流体力学方法通常依赖网格离散化，在复杂几何边界上面临网格生成困难。近年来，基于随机游走的 Monte Carlo PDE 求解方法——特别是 Walk-on-Spheres（WoS）——被引入流体仿真领域，提供了完全无网格的求解途径。

2022 年，Rioux-Lavoie、Sugimoto 等人提出了首个 Monte Carlo 流体仿真框架\cite{rioux2022}。该方法采用\textbf{涡量-速度}表示：以涡量 $\omega$ 为状态变量，通过 Biot-Savart 定律由涡量重建速度，边界条件通过流函数 $\psi$ 与 WoS 算法处理。由于 Biot-Savart 重建的速度场天然无散，该方法\textbf{无需压力投影}，从根本上避免了不可压缩性约束的数值实现难题。

2024 年，Sugimoto、Batty 和 Hachisuka 提出\textbf{基于速度}的 Monte Carlo 方法\cite{sugimoto2024}。该方法直接以速度场 $\boldsymbol{u}$ 为状态变量，采用经典算子分裂框架（平流→外力→扩散→投影），其中投影步骤用 Walk-on-Boundary（WoB）边界积分直接估计压力梯度 $\nabla p$。由于速度法直接使用速度场，可以方便地融入浮力、PIC/FLIP 等传统速度法技术，但需要显式维持 $\nabla\cdot\boldsymbol{u}=0$。

本实验对比实现了这两种算法：
\begin{itemize}
    \item \textbf{2022 涡量法}：参考合作者的实现（\texttt{2022\_Simulation/}），包括 2D 涡量输运 + Biot-Savart、流函数 WoS 边界、3D 涡拉伸等完整管线；
    \item \textbf{2024 速度法}：本实验实现（\texttt{fluid\_sim\_wob.py}），速度算子分裂 + WoB 特解投影。
\end{itemize}

两者均使用 Numba JIT 加速，在 Taylor-Green 涡流场上从相同初始条件出发进行对比，考察动能演化、涡量守恒和计算效率。

\section{算法原理}

\subsection{2022 涡量法}

\subsubsection{涡量输运方程}

2022 年方法的理论基础是二维不可压缩流的\textbf{涡量输运方程}。对于无粘外流，涡量 $\omega = \partial v/\partial x - \partial u/\partial y$ 沿流线输运：
\begin{equation}
\frac{D\omega}{Dt} = \frac{\partial \omega}{\partial t} + \boldsymbol{u}\cdot\nabla\omega = 0.
\label{eq:vort_transport}
\end{equation}

采用半拉格朗日后向追踪离散：
\begin{equation}
\omega(\boldsymbol{x}, t) = \omega(\boldsymbol{x} - \Delta t\,\boldsymbol{u}(\boldsymbol{x},t),\, t-\Delta t).
\end{equation}

\subsubsection{Biot-Savart 重建速度}

从涡量场重建速度场的关键是 Biot-Savart 定律。在 2D 中，速度与涡量的关系为
\begin{equation}
\boldsymbol{u}(\boldsymbol{x}) = \int_{\mathbb{R}^2} \boldsymbol{B}(\boldsymbol{x},\boldsymbol{y})\,\omega(\boldsymbol{y})\,d\boldsymbol{y},
\label{eq:biot_savart}
\end{equation}
其中 Biot-Savart 核为
\begin{equation}
\boldsymbol{B}(\boldsymbol{x},\boldsymbol{y}) = \frac{1}{2\pi}\frac{(y_y - x_y,\; -(y_x - x_x))}{|\boldsymbol{x}-\boldsymbol{y}|^2}.
\end{equation}

该积分通过 Monte Carlo 估计：在计算域内均匀采样点 $\boldsymbol{y}_i$，估计速度
\begin{equation}
\boldsymbol{u}(\boldsymbol{x}) \approx \frac{1}{N}\sum_{i=1}^N \frac{\boldsymbol{B}(\boldsymbol{x},\boldsymbol{y}_i)}{p(\boldsymbol{y}_i)}\,\omega(\boldsymbol{y}_i),
\end{equation}
其中 $p$ 为采样概率密度。\textbf{关键性质}：Biot-Savart 重建的速度场自动满足 $\nabla\cdot\boldsymbol{u}=0$，因此涡量法\textbf{无需任何投影步骤}。

\subsubsection{边界处理：流函数 + WoS}

对于存在固体的边界，2022 年论文引入\textbf{流函数} $\psi$。流函数满足
\begin{equation}
\nabla^2 \psi = -\omega, \qquad \boldsymbol{u} = \nabla\times\psi = \left(\frac{\partial\psi}{\partial y},\,-\frac{\partial\psi}{\partial x}\right).
\end{equation}

流函数 Poisson 方程 $\nabla^2\psi = -\omega$ 通过 Walk-on-Spheres（WoS）算法求解。WoS 利用 Brown 运动的均值性质：从点 $x_k$ 出发，到边界的距离为 $d_k$，随机跳至球面 $x_{k+1} = x_k + d_k(\cos\theta,\sin\theta)$。对 Poisson 方程 $\nabla^2 u = f$，Feynman-Kac 公式给出
\begin{equation}
u(x) = \mathbb{E}[g(B_\tau)] - \mathbb{E}\left[\int_0^\tau f(B_s)\,ds\right],
\end{equation}
其 WoS 离散形式为源项按 $\frac{d_k^2}{4}f(x_k)$ 累积，直至到达边界（$d_k < \varepsilon$）。

\subsection{2024 速度法}

\subsubsection{算子分裂}

2024 年方法直接以速度场为状态，采用经典算子分裂框架（Stam 1999）求解不可压缩 Navier-Stokes 方程：
\begin{equation}
\frac{\partial\boldsymbol{u}}{\partial t} = -(\boldsymbol{u}\cdot\nabla)\boldsymbol{u} - \nabla p + \nu\nabla^2\boldsymbol{u} + \boldsymbol{f}, \qquad \nabla\cdot\boldsymbol{u}=0.
\end{equation}

每个时间步分解为四个子步骤：
\begin{enumerate}[label=(\arabic*)]
    \item \textbf{平流}：半拉格朗日后向追踪，$\boldsymbol{u}^*(\boldsymbol{x}) = \boldsymbol{u}^n(\boldsymbol{x}-\boldsymbol{u}^n\Delta t)$；
    \item \textbf{外力}：$\boldsymbol{u}^{**} = \boldsymbol{u}^* + \Delta t\,\boldsymbol{f}$；
    \item \textbf{扩散}：WoS/Feynman-Kac 求解 $\partial\boldsymbol{u}/\partial t = \nu\nabla^2\boldsymbol{u}$；
    \item \textbf{投影}：$\nabla^2 p = \nabla\cdot\boldsymbol{u}$，$\boldsymbol{u}^{n+1} = \boldsymbol{u} - \nabla p$，维持 $\nabla\cdot\boldsymbol{u}=0$。
\end{enumerate}

\subsubsection{WoB 投影}

投影步骤需要求解压力 Poisson 方程 $\nabla^2 p = \nabla\cdot\boldsymbol{u}$。2024 年论文提出用 Walk-on-Boundary（WoB）边界积分直接估计 $\nabla p$，而非求解标量 $p$。

由于完整 WoB 多弹跳路径积分需要 GPU 加速，本实验采用\textbf{特解 + 边界修正}的简化实现。将解分解为自由空间特解 $p_p$ 与调和修正 $p_h$：
\begin{equation}
p(\boldsymbol{x}) = p_p(\boldsymbol{x}) + p_h(\boldsymbol{x}),
\end{equation}
其中
\begin{equation}
p_p(\boldsymbol{x}) = \int_\Omega \frac{1}{2\pi}\ln|\boldsymbol{x}-\boldsymbol{y}|\,f(\boldsymbol{y})\,d\boldsymbol{y}, \qquad
p_h(\boldsymbol{x}) = \mathbb{E}\left[-p_p(\boldsymbol{y}_{\partial\Omega})\right].
\end{equation}

$p_h$ 中的期望通过 WoB 射线采样：从 $\boldsymbol{x}$ 出发沿均匀随机方向发射射线至矩形边界，$\boldsymbol{y}_{\partial\Omega}$ 为首次撞点。对凸域而言该采样等价于调和测度，因而是正确的。得到 $p$ 后，用中心差分计算 $\nabla p$ 修正速度。

\section{代码实现}

\subsection{2022 涡量法实现}

2022 涡量法的实现位于 \texttt{2022\_Simulation/}，包含四个递进阶段：

\begin{itemize}
    \item \texttt{mc\_fluid\_step1\_py}（2D 无粘）：涡量输运 + 均匀采样 Biot-Savart + 半拉格朗日平流 + 网格缓存；
    \item \texttt{mc\_fluid\_step2\_py}（2D 边界）：流函数 + WoS 求解 $\nabla^2\psi=-\omega$ + 对偶采样，支持自由滑移边界；
    \item \texttt{mc\_fluid\_step3\_py}（3D）：3D Biot-Savart + Feynman-Kac 粘性扩散 + 涡拉伸；
    \item \texttt{mc\_fluid\_step4\_py}（3D 方差缩减）：重要性采样 + 控制变量。
\end{itemize}

该实现遵循论文的涡量-速度公式，以涡量场为状态变量，速度场完全由 Biot-Savart 积分重建，无需压力投影。

\subsection{2024 速度法实现}

2024 速度法由本实验实现，核心组件：

\begin{itemize}
    \item \texttt{numba\_wos.py}：Numba 加速的 WoS 求解器 + WoB 射线求交 + WoB 特解 Poisson 求解；
    \item \texttt{fluid\_sim\_wob.py}：速度算子分裂完整管线（平流 → 扩散 → WoB 投影）；
    \item \texttt{wos\_core.py}：纯 Python 参考实现。
\end{itemize}

WoB 投影的核心是 $p(\boldsymbol{x}) = p_p(\boldsymbol{x}) - \mathbb{E}[p_p(\boldsymbol{y}_{\partial\Omega})]$，通过 Numba \texttt{@njit(parallel=True)} 实现多网格点并行。

\section{实验结果与分析}

\subsection{实验设置}

两种方法在相同的 Taylor-Green 涡流场上对比。Taylor-Green 涡的初始条件为
\begin{equation}
\boldsymbol{u}_0 = \bigl(-\cos(\pi x)\sin(\pi y),\; \sin(\pi x)\cos(\pi y)\bigr)^\top,
\end{equation}
对应的涡量场为 $\omega_0 = 2\pi\cos(\pi x)\cos(\pi y)$。计算域为 $[-1,1]^2$，网格 $16\times16$，时间步长 $\Delta t=0.03$，运行 15 步。为聚焦算法本身的差异，两者均在无粘（$\nu=0$）条件下运行。

\subsection{结果分析}

从表 \ref{tab:2022_2024} 和图 \ref{fig:ke_comparison} 可以得出以下结论：

\begin{itemize}
    \item \textbf{计算效率（最显著的差异）}：2022 涡量法每步需为每个网格点执行全域 Biot-Savart 积分（256 次核函数评估），60 步耗时 \textbf{30.8 s}；2024 速度法借助网格缓存，仅需 \textbf{0.9 s}，快约 \textbf{34 倍}。这是涡量法最主要的实用短板。

    \item \textbf{数值耗散}：在无粘条件下，两种方法的动能均显著衰减——涡量法 $-76\%$，速度法 $-68\%$。这表明两种方法的主要耗散来源都是半拉格朗日平流的插值误差和网格缓存分辨率，而非状态变量选择本身。长时间演化下两者的耗散行为趋于一致。

    \item \textbf{涡量保持}：两种方法对最大涡量的保持相近（$\omega_{\max}$ 均降至初始的约 $54\%$）。涡量法直接演化涡量场，但 Biot-Savart 重建与插值同样引入耗散；速度法通过投影维持不可压缩性，涡量由速度场差分得到，耗散略大但量级接近。

    \item \textbf{稳定性}：两种方法在各自框架下均稳定运行。涡量法速度由积分重建，天然满足 $\nabla\cdot\boldsymbol{u}=0$ 且无投影噪声反馈；速度法依赖 WoB 投影，但投影噪声步间独立，不形成正反馈发散。
\end{itemize}

\subsection{讨论}

\textbf{2022 涡量法的优势与代价。} 涡量法的核心优势是\textbf{天然不可压缩性}：速度由 Biot-Savart 积分重建，自动满足 $\nabla\cdot\boldsymbol{u}=0$，避免了投影步骤及其噪声。同时，涡量作为状态变量便于涡旋动力学分析。其主要代价是 Biot-Savart 积分的计算开销——每次速度查询需遍历全域采样，在细网格上成本急剧上升（实验中为速度法的 34 倍）。此外，涡量法在三维中需要处理涡拉伸项，且在非单连通区域面临调和场问题\cite{sugimoto2024}。

\textbf{2024 速度法的优势与代价。} 速度法直接操作速度场，计算高效，且能自然融入浮力、PIC/FLIP、平流-反射等传统速度法技术。其代价是需要显式维持不可压缩性：投影步骤在有限 MC 采样下引入噪声，若采用 WoS 压力 Poisson + 有限差分梯度，噪声会形成正反馈发散；改用 WoB 特解投影后噪声步间独立，解决了这一问题，但数值耗散仍然较大。

\textbf{选择建议。} 两种方法各有适用场景：涡量法适合强调物理守恒的研究性仿真（涡旋动力学、环量分析）；速度法适合追求效率与可扩展性的动画级应用（可结合 GPU 并行、方差缩减技术）。

\section{结论与展望}

本实验实现了 2022 年 Rioux-Lavoie et al. 的涡量法和 2024 年 Sugimoto et al. 的速度法，并在相同测试条件下进行了对比。主要结论如下：

\begin{enumerate}[label=(\arabic*)]
    \item \textbf{两种算法均已实现}：涡量法（涡量输运 + Biot-Savart + 流函数 WoS）和速度法（算子分裂 + WoB 投影）均可稳定运行。
    \item \textbf{计算效率}：速度法快约 \textbf{34 倍}（0.9 s vs 30.8 s，$16\times16$ 网格 60 步），网格缓存使投影步骤成本远低于全域 Biot-Savart 积分。这是两种方法最显著的实用差异。
    \item \textbf{数值耗散相近}：在无粘条件下长时间演化（$t=1.8$）中，两者动能均衰减约 $68\%$--$76\%$，耗散主要源于半拉格朗日平流插值而非状态变量选择。
    \item \textbf{不可压缩性}：涡量法天然满足 $\nabla\cdot\boldsymbol{u}=0$，速度法依赖投影步骤；WoB 投影的步间独立噪声避免了 WoS 压力 Poisson + 有限差分的正反馈发散问题。
\end{enumerate}

展望未来，以下方向值得探索：
\begin{itemize}
    \item \textbf{方差缩减}：对涡量法引入重要性采样、控制变量（参考合作者 Phase 4）；对速度法引入 antithetic variates；
    \item \textbf{GPU 加速}：Biot-Savart 积分天然并行，适合 GPU 批量加速；WoB 投影可复用 NVIDIA WoSX 框架\cite{sawhney2023wosx}；
    \item \textbf{混合方法}：在速度法框架中利用涡量信息增强物理守恒，或反之；
    \item \textbf{3D 扩展}：涡量法需处理涡拉伸，速度法需处理向量势的规范自由度，两者在 3D 中都需额外设计。
\end{itemize}
